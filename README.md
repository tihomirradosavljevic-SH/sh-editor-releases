# Editor Master — Releases

This repo hosts the installers for **Editor Master**, the SpotHopper internal desktop tool for processing Website Editor tasks from Jira.

There is no source code here — only release binaries and update metadata.

## Install (one time)

1. Go to the **[latest release](https://github.com/tihomirradosavljevic-SH/sh-editor-releases/releases/latest)** and download `Editor-Master-Setup-X.Y.Z.exe`
2. Windows will show *"Windows protected your PC"* — click **More info → Run anyway** (expected, the app isn't code-signed)
3. In the installer choose **"Only for me"**
4. Done

## Updates

You never need to come back here. The app checks this repo on every launch — when a new version is out, a banner appears inside the app; one click installs it and restarts.

## Files in each release

| File | What it's for |
|---|---|
| `Editor-Master-Setup-X.Y.Z.exe` | **The installer — this is the only file you need** |
| `latest.yml` | Update metadata read by the app |
| `*.blockmap` | Enables differential (smaller) update downloads |
| Source code (zip/tar.gz) | Auto-generated by GitHub, ignore |

## Prerequisites (only for Editor Claude / Add Video modes)

- Node.js LTS
- Claude Code CLI: `npm install -g @anthropic-ai/claude-code`, then run `claude` once to log in
- Skill files copied to `%USERPROFILE%\.claude\commands\` (provided separately)

The default **Editor** mode needs none of the above — install and go.
